What is RAG & How Does It Work? (AI Primer)

Designed for 1st-year CS students starting their AI journey: technical definitions, core mechanics, and key AI concepts explained from first principles.

Technical Definition Lewis et al., 2020 📄

Retrieval-Augmented Generation (RAG) is an AI system pattern that pairs an **autoregressive Large Language Model (LLM)** with an **external non-parametric retriever** (e.g. vector database).

Formulaic Overview:
Given query $q$, RAG computes:
1. $P_{\text{retrieval}}(d \mid q) \implies$ Top-$k$ relevant passages $D$
2. $P_{\text{generator}}(y \mid q, D) \implies$ Generated response tokens $y$
Dual Memory Architecture Parametric vs. Non-Parametric

Understanding the two distinct types of memory in modern AI systems:

  • Parametric Memory: The frozen weight matrices ($W \in \mathbb{R}^{m \times n}$) inside the neural network. Hard to update without expensive retraining.
  • Non-Parametric Knowledge Base: An external database (e.g. Postgres + `pgvector`). Instantly updated with simple $O(1)$ SQL `INSERT` statements!

The 3 Technical Stages of RAG Mechanics

Stage 1: Dense Retrieval

1. Tokenization: Query text $q$ is converted into token IDs.
2. Dense Vector Embedding: Passed into an Encoder Model (`nomic-embed-text`) to produce high-dimensional vector $\vec{q} \in \mathbb{R}^{768}$.
3. $k$-NN Search: Nearest Neighbors search in vector space using Cosine Similarity ($\cos\theta$).

Stage 2: Prompt Augmentation

1. Top-$k$ retrieved chunks $\{c_1, c_2, \dots, c_k\}$ are extracted.
2. A structured Augmented Prompt is built.
3. Leverages In-Context Learning: The LLM reads the context using Self-Attention ($Q, K, V$ matrices) without mutating its model weights.

Essential AI Glossary for 1st-Year CS Students

Tokenization

The process of splitting raw text strings into numerical sub-word units (Tokens) that neural networks can process.

Embedding Vector

A dense array of real numbers (e.g. 768 floats) representing text semantics in high-dimensional latent space.

Cosine Similarity

A mathematical metric measuring the cosine of the angle $\theta$ between two vectors: $\cos(\theta) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \|\mathbf{B}\|}$.

Context Window

The maximum number of tokens an LLM can process simultaneously in its Self-Attention memory at inference time.

Hallucination

When a generative model generates statistically plausible but factually incorrect statements due to ungrounded parametric memory.

In-Context Learning

The ability of Transformer models to follow instructions and extract facts directly from the prompt without fine-tuning weights.

The Mental Model: Closed-Book vs. Open-Book

Why can't we just ask a Large Language Model (LLM) direct questions about clinic records?

Standard LLM Closed-Book Exam ❌

The model answers using only its pre-trained memory. Since it was never trained on your private clinic database, it has two bad options: refuse or guess.

Result: Hallucination
User: "What vaccines has Max received?"
LLM: "Max received Rabies on June 5th." (Completely fabricated!)
RAG Architecture Open-Book Exam ✅

Before answering, the system first retrieves real records from Postgres, attaches them to the prompt, and instructs the LLM to write a response using only that context.

Result: Authoritative & Verifiable
RAG System: "Based on record #1042, Max received his DHPP vaccine on Jan 10, 2024."

Vector Embeddings & Semantic Search

Traditional string search relies on exact keyword matches. Vector embeddings map human language into points on a 768-dimensional map where similar meanings are close together.

Cosine Similarity Math

Similarity = cos(θ) = (A · B) / (||A|| ||B||)


How pgvector queries the DB:

SELECT content, 1 - (embedding <=> $1) AS similarity
FROM vector_store
ORDER BY embedding <=> $1 ASC
LIMIT 3;

Hybrid Query Routing: Avoiding RAG Flaws

RAG is great for semantic search, but terrible at exact counting (vector search only returns top-K chunks, not the whole DB!). VetCare Pro uses a hybrid router.

flowchart TD
    Start["User Question Arrives"] --> Q1{"Action Request?

Extract JSON params + Await Human Confirmation"]
    
    Q1 -- No --> Q2{"Exact Count / List?
'How many dogs registered?'"}
    Q2 -- Yes --> SQL["structured_query.py
Execute SELECT COUNT(*) directly (No AI guessing!)"]
    
    Q2 -- No --> RAG["retrieval.py

Multi-Tenant Role Security Isolation

Security is enforced at the database query layer so private clinic data never reaches the LLM context for unauthorized users.

Role Permissions Postgres Query Clause (`retrieval.py`)
Guest Public FAQs & general advice only WHERE role_scope = 'public_faq'
Pet Owner Own pets' medical & billing records WHERE role_scope IN ('public_faq', 'pet_owner') AND customer_id = $auth_user
Staff / Vet Full clinic medical records WHERE role_scope IN ('public_faq', 'pet_owner', 'staff')
